# Babalas Rescue+ — design backbone

Single home for all design work for **Babalas Rescue+** (hangover-recovery drinks, South Africa).
Start with the brand guide, then build everything from the tokens and logo files.

| Open this | For |
|---|---|
| `brand/brand-identity.html` (PDF: `brand/exports/babalas-brand-identity.pdf`) | Full brand identity: essence, voice, logo, colour, type, graphic language, products |
| `brand/moodboard.html` (PNG/PDF: `brand/exports/`) | Brand mood board |
| `brand/BRAND-IDENTITY.md` | Quick-reference summary (paste into briefs and prompts) |
| `brand/brand-tokens.css` | CSS variables for colour, type, shape. Import into every HTML design |
| `brand/logo/` | SVG + PNG logo colourways, icon and wordmark |
| `brand/assets/` | Web-sized product packshots |
| `source-assets/` | Original files pulled from Google Drive |
| `scripts/build_logos.py` | Rebuilds logo colourways from the supplied PDF |
